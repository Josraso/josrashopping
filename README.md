# Josra Shopping Feed (josrashopping)

Módulo para PrestaShop (1.6.1 a 9) que genera el feed de productos para **Google Merchant Center** (Google Shopping).

- Asistente de primera configuración para gente sin conocimientos técnicos.
- Diagnóstico de los productos que Google rechazará antes de enviarlos.
- Categorías de Google con buscador de la taxonomía oficial.
- El feed se regenera solo; tarea programada opcional.

La ayuda está dentro del propio módulo (Módulos > Josra Shopping Feed > Configurar).
